Metadata Scrubber

The file-cleaning engine from the messenger, as an app of its own. It removes the second payload a file carries: GPS coordinates, camera serial numbers, the author's name, the editing session identifiers that link two documents to one machine.

✓
The engine is real and already tested. 131 unit tests, 20,000 mutation iterations with no panics, and a run over 65 real files across PDF, JPEG, OOXML, WebP and PNG. Only the interface below is a mockup.

Complete

The container was rebuilt from a keep-list. Nothing outside that list survived, including structures the tool does not recognise.

Best effort

Known metadata was found and removed, but the container was not rebuilt from scratch. The warnings say exactly what was not guaranteed.

Not cleaned

The format could not be taken apart, so the file was returned untouched. No output is written. This is the honest answer, not a failure to hide.
